# Krysta Launcher 1.0.17

- Naprawiono odmowę dostępu do obrazu gry podczas uruchamiania nagrywania. Pierwsze F9 rozpoczyna nagrywanie aktywnej gry wykrytej przez Krystę, a kolejne kończy nagrywanie i zapisuje klip w zakładce **Nagrania**.
- Przechwytywanie obrazu korzysta z uprawnienia przyznawanego wyłącznie oknu nagrywającemu. W razie niepowodzenia szczegóły błędu są w zakładce **Nagrania**.

Wydanie dla Windows x64 zawiera instalator, wersję przenośną i sumy SHA-256.
