# Krysta Launcher 1.0.15

## Nagrywanie gier

- F9 jest domyślnym skrótem ręcznego nagrywania. Pierwsze naciśnięcie rozpoczyna nagranie, a drugie je zapisuje. Ustawienia ze starym domyślnym skrótem Ctrl+Shift+F9 przechodzą na F9. Skrót można zmienić w ustawieniach nagrywania.
- Po przełączeniu z okna gry Krysta kończy i zapisuje rozpoczęty klip ręczny. Po powrocie do gry można nagrać kolejny.
- Zakładka „Nagrania” pokazuje komunikat, gdy skrót jest zajęty albo Krysta nie może przechwycić okna gry.

Wydanie dla Windows x64 zawiera instalator, wersję przenośną i sumy SHA-256.
