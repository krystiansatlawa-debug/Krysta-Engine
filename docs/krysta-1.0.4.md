# Krysta Launcher 1.0.4

Wydanie dla Windows x64 dodaje historię sesji i odczyt postępu z lokalnych zapisów.

- **Dziennik gry** zapisuje rozpoczęcie, zakończenie i długość sesji wykrytych przez Krystę.
- **Postęp fabuły** korzysta ze ścieżek wykrytych przez Cloud Save i Ludusavi. Możesz też wskazać własny folder zapisów. Krysta odświeża dane po zamknięciu wykrytej gry.
- **GTA V Legacy, GTA V Enhanced i RDR2** pokazują tytuł zapisu i procent ukończenia całej gry. **Cyberpunk 2077** pokazuje śledzone zadanie lub jego identyfikator. Krótkie opisy są dostępne dla wybranych misji.
- Na kartach gier można ręcznie zapisać procent ukończenia, nazwę aktualnej misji i jej opis.

Wydanie zawiera instalator, wersję portable i sumy kontrolne SHA-256.
