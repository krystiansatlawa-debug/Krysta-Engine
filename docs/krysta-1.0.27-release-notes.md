## Krysta Engine 1.0.27 – Kontrolery, pulpit i ekrany

### Kontrolery

- Wspólna zakładka **Kontrolery** w zwykłej Kryście i Big Picture. Zapisane profile Xbox i DualSense pozwalają ustawić przypisania przycisków, prędkość kursora i martwą strefę dla każdego pada.
- Opcjonalne sterowanie pulpitem Windows obejmuje kliknięcia, przewijanie oraz przeciąganie plików i okien. Moduł wstrzymuje sterowanie podczas śledzonej gry i wznawia je po jej zakończeniu.
- Klawiaturę ekranową Windows można wywołać skrótem pada lub automatycznie po wejściu do obsługiwanego pola edycji. Profil pozwala przypisać zaznaczanie, kopiowanie i wklejanie.
- Włączony moduł uruchamia się razem z Krystą i pracuje w zasobniku systemowym. Można go wyłączyć z ustawień lub menu zasobnika.

### Ekrany i dźwięk

- Przełączanie obrazu Windows między wyświetlaczami, duplikowanie i rozszerzanie pulpitu oraz zapamiętywanie preferowanego ekranu.
- Opcjonalne przełączenie na TV przy otwarciu Big Picture i przywrócenie poprzedniej konfiguracji po zakończeniu gry. Obsługa odłączenia telewizora i automatycznego wyboru dźwięku HDMI dla rozpoznanego urządzenia audio.

### Pliki i weryfikacja

- `krysta-launcher-1.0.27-setup.exe` — instalator Windows x64.
- `krysta-launcher-1.0.27-portable.exe` — wersja Windows x64 bez instalacji.
- `krysta-launcher-1.0.27-sha256.txt` — sumy kontrolne obu plików EXE.
- Fizyczne kontrolery Xbox i DualSense, konfiguracje monitor/TV z HDMI oraz rzeczywiste zużycie RAM i CPU — niezweryfikowane sprzętowo.
