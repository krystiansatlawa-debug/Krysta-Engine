# Krysta Launcher 1.0.8 — ręczne nagrywanie START/STOP

- Dodano ręczne nagrywanie rozgrywki bez zdobywania osiągnięcia.
- Wybrany skrót nagrywania (np. F9) rozpoczyna nagrywanie; ponowne naciśnięcie zatrzymuje je i zapisuje film WebM.
- W zakładce „Nagrania” widać stan nagrywania i przycisk „Zatrzymaj”.
- Zachowano krótkie klipy wyzwalane osiągnięciami oraz bufor powtórek.
- Ulepszono opisy ustawień i dodano test ręcznego START/STOP.

**Ograniczenia:** Nagrywanie działa na Windows przy włączonej funkcji i rozpoznanym aktywnym oknie gry. W ustawieniach należy wybrać F9 — zapisany wcześniej skrót nie jest automatycznie zmieniany. Limit rozmiaru pojedynczego WebM wynosi około 96 MB. Zamknięcie gry lub utrata aktywnego okna może przerwać nagrywanie bez zapisu.
