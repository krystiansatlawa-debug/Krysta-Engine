# Krysta Launcher 1.0.21

- Drugie naciśnięcie przycisku Xbox przywraca grę na cały monitor także wtedy, gdy przed minimalizacją działała w oknie.
- Krysta najpierw pozwala grze włączyć własny pełny ekran. Jeśli gra pozostaje w oknie, Krysta rozszerza je na cały monitor i usuwa obramowanie.

Wydanie dla Windows x64 zawiera instalator, wersję przenośną i sumy SHA-256.
