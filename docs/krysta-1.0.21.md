# Krysta Launcher 1.0.21

- Drugie naciśnięcie przycisku Xbox przywraca grę i przełącza ją na jej własny pełny ekran za pomocą **Alt+Enter**, jeśli gra obsługuje ten skrót. Działa to także przy powrocie do gry, która przed minimalizacją była w oknie.

Wydanie dla Windows x64 zawiera instalator, wersję przenośną i sumy SHA-256.
