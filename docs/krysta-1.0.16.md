# Krysta Launcher 1.0.16

## Kontroler Xbox

- W **Ustawienia → Gra → Kontroler Xbox** można włączyć minimalizowanie i przywracanie gry podświetlanym przyciskiem Xbox.
- Pierwsze naciśnięcie minimalizuje aktywne okno gry wykrytej przez Krystę. Drugie przywraca to samo okno. Gra pozostaje uruchomiona, a jej zachowanie w tle zależy od ustawień gry.
- Jeśli naciśnięcie otwiera Game Bar, można w ustawieniach Windows wyłączyć otwieranie paska za pomocą kontrolera.

Wydanie dla Windows x64 zawiera instalator, wersję przenośną i sumy SHA-256.
