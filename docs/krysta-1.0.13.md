# Krysta Launcher 1.0.13

## Postęp fabuły

- Krysta rozpoznaje metadane kampanii po zawartości pliku, również w zapisach `.sav`, `.save`, `.dat` i `.bin`. Obsługuje tekstowe zapisy UTF-16, metadane XML z zagnieżdżonymi polami oraz pliki skompresowane gzip.
- Gdy zapis zawiera nazwę rozdziału bez procentu ukończenia, karta gry może pokazać sam rozdział.
- Jeżeli pierwszy znaleziony zapis nie zawiera czytelnych informacji o fabule, Krysta sprawdza też pliki wykryte przez Ludusavi lub w folderze zapisów gier Epic, gdy są dostępne.

Zaszyfrowane i własne binarne formaty gier mogą nadal wymagać osobnego czytnika. Wydanie dla Windows x64 zawiera instalator, wersję przenośną i sumy SHA-256.
