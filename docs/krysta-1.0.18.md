# Krysta Launcher 1.0.18

- W **Ustawienia → Multimedia → Nagrania** można wybrać przycisk kontrolera Xbox do nagrywania gry. Pierwsze naciśnięcie rozpoczyna nagrywanie, a drugie zapisuje klip w zakładce **Nagrania**.
- Dostępne są standardowe przyciski XInput, w tym View, Menu, krzyżak i spusty. Podczas gry można też używać klawisza F9 lub innego ustawionego skrótu klawiatury.
- Podświetlany przycisk Xbox służy do minimalizowania i przywracania gry, jeśli włączono tę funkcję w **Ustawienia → Gra → Kontroler Xbox**.
- Wydanie zawiera poprawkę uruchamiania nagrywania z wersji 1.0.17.

Wydanie dla Windows x64 zawiera instalator, wersję przenośną i sumy SHA-256.
